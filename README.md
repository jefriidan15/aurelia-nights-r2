# Aurelia Nights

A top-down open-world crime game set in **Port Aurelia** — a 3600×2600 city with six districts (Old Town, Downtown, Marina, Little Vesper, Midtown, The Docks) plus the harbour and Pier 9.

Steal cars, dodge a five-star police force, grab street cash, and run six story jobs to take the city.

## Play

Open `game/index.html` in a browser, or serve the `game/` folder:

```
bun serve.ts
```

then open `http://localhost:8080`.

## Controls

| Input | Action |
| --- | --- |
| WASD / Arrows | Walk |
| Shift | Sprint |
| Mouse | Aim |
| Click / Space | Fire |
| E | Steal a car / enter a shop / exit a car |
| W/S/A/D (driving) | Accelerate / brake / steer |
| Space (driving) | Handbrake |
| H (driving) | Horn |
| Q | Switch weapon |
| M | Job board |
| P | Pause |
| F1 | Mute |

## The six jobs

1. **Grand Theft Aurelia** — $400: boost a ride, drop it at the Marina.
2. **Heat Wave** — $600: pick up a package at Pier 9, deliver it hot.
3. **Pier 9 Shootout** — $900: clear the Docks crew, take the stash.
4. **The Vault Job** — $1,500: crack the Downtown bank vault, escape to Rosa's Flat.
5. **Four-Star Run** — $2,000: hit four stars, outrun the law to the Marina.
6. **Lockdown** — $3,500: survive ninety seconds at five stars, reach the harbour boat.

Finish all six to win.

## The city

- **16 traffic cars** and **8 parked cars** to steal; **30 pedestrians** who flee gunfire.
- **5-star wanted system**: cops chase on foot, ram your car, shoot at 3+ stars, and arrest you if they get close.
- **5 shops**: Lola's Spray Shop ($100 — wipe wanted + repair), Iron & Oak (pistol $150, shotgun $400, ammo $25), The Golden Gull diner, St. Aurelia General hospital, Rosa's Flat safehouse (save + heal).
- **Street cash** pickups ($25–$75), day/night cycle with headlights, synthesized WebAudio sound (no audio files), HUD + minimap, localStorage saves.
